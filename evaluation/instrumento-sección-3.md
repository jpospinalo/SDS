# Sección 3. Composición / información sobre los componentes

Esta sección identifica los componentes del producto. En el caso de **mezclas**, se deben indicar los componentes que deban declararse, junto con su identidad química, su número CAS u otro identificador único y su concentración exacta o rango de concentración.

## Instrumento de evaluación de la Sección 3

Instrumento construido con base en **A4.3.3, A4.3.3.2, A4.3.3.2.1, A4.3.3.2.2 y A4.3.3.1.3 del SGA Rev. 6 (2015)**.

Este instrumento cubre los componentes obligatorios de la **Sección 3** aplicables a **mezclas** previstos en **A4.3.3.2.1 y A4.3.3.2.2**.

En este instrumento, la posibilidad normativa de listar ingredientes adicionales o ingredientes no sujetos a declaración en la **Sección 3** **no puntúa como requisito obligatorio**. Si esa información aparece, se registra en **Observaciones** y no modifica por sí sola la calificación del ítem.

# Regla de calificación

## Criterio general
La asignación de **5, 3 o 1** se realiza únicamente con base en **atributos observables en la propia Sección 3 de la FDS**.

## Regla operativa
- **5**: se observan todos los atributos exigibles del ítem.
- **3**: se observa al menos un atributo exigible del ítem, pero no todos.
- **1**: no se observa ningún atributo exigible del ítem.

# Regla de aplicación

- Solo se evalúa la información consignada en la **Sección 3** de la FDS.
- No se permite completar, corregir ni contrastar información con fuentes externas.
- No se infiere información a partir del producto físico, otras secciones de la FDS o conocimiento técnico del evaluador.
- Este instrumento se aplica a **FDS de pinturas que corresponden a mezclas**.
- La propia FDS debe declarar expresamente que el producto es una **mezcla**.
- Cuando un atributo depende de una condición previa, solo se exige si esa condición está escrita en la FDS.
- No se incorporan exigencias distintas de las previstas en la base normativa declarada para este instrumento.
- No se exige información tomada de otras secciones, salvo que el propio instrumento lo declare de forma explícita.

# Regla de precedencia

En caso de duda o aparente tensión entre disposiciones del instrumento, se aplicará el siguiente orden:
1. **Tabla del ítem**
2. **Regla de aplicación**
3. **Nota de aplicación del ítem**
4. **Formato resumido**

# Regla sobre “No corresponde”

- **No corresponde** se utiliza únicamente cuando la exigibilidad del atributo depende de una condición previa escrita en la propia Sección 3.
- **No corresponde** no debe usarse cuando la información no se encuentra, cuando la redacción es ambigua o cuando el evaluador no puede confirmar el dato.
- En **3.2.4**, el ítem se marca como **No corresponde** cuando la propia FDS declara expresamente que no existen componentes que deban declararse y, por tanto, no presenta una lista de componentes sobre la cual pueda formularse una declaración de cierre adicional.

# Notas de aplicación por ítem

## 3.0
- Solo se evalúa el encabezado de la sección.
- No se infiere el título a partir del contenido interno.
- Para el atributo 2, solo se aceptan las siguientes expresiones: **Composición / información sobre los componentes**, **Composición e información sobre los componentes**, **Información sobre los componentes** o **Composición**.

## 3.1
- Este ítem verifica que la propia FDS declare expresamente que el producto es una **mezcla**.
- Que el producto pertenezca al universo de estudio no sustituye esa declaración.
- No se infiere que el producto es mezcla a partir del conocimiento externo del evaluador.

## 3.2.1
- La identidad química se evalúa solo sobre los componentes efectivamente listados o sobre una declaración expresa de que no existen componentes que deban declararse.
- Una declaración expresa de ausencia de componentes que deban declararse se califica mejor que la omisión de información.
- Si la FDS contiene solo **contiene ingredientes** o **mezcla de componentes**, sin individualización de cada componente, el ítem se califica con **3**.
- Si la FDS contiene solo **propietario**, **confidencial** o **secreto comercial** como nombre del componente, sin individualización adicional, el ítem se califica con **3**.

## 3.2.2
- Se acepta número CAS u otro identificador único, siempre que la propia FDS lo consigne en el mismo renglón, celda o bloque de texto que el componente correspondiente.
- La omisión del identificador no se trata igual que una declaración expresa de ausencia de componentes que deban declararse.
- Si la FDS lista dos o más componentes y no consigna cada identificador en el mismo renglón, celda o bloque de texto del componente correspondiente, el ítem se califica con **3**.
- Si la FDS consigna solo **confidencial**, **propietario** o **secreto comercial** en el campo del identificador, esa información no satisface el atributo 1.

## 3.2.3
- Se acepta concentración exacta o rango de concentración.
- La concentración o el rango se evalúan solo cuando la propia FDS los consigna en el mismo renglón, celda o bloque de texto del componente correspondiente.
- El orden descendente solo se evalúa cuando la propia FDS lista dos o más componentes con valores que permiten comparación directa sin conversión externa.
- Si la FDS consigna solo **trazas**, **mínimo** o **máximo** sin número y sin rango, esa información no satisface el atributo 1.
- Si la FDS consigna solo **confidencial**, **propietario** o **secreto comercial** en el campo de concentración, esa información no satisface el atributo 1.

## 3.2.4
- Este ítem evalúa si la FDS cierra expresamente la lista de componentes reportados.
- Para el atributo 2, solo se aceptan las siguientes fórmulas: **no contiene componentes adicionales que deban declararse**, **no hay componentes adicionales sujetos a declaración en esta sección** o **no existen otros componentes peligrosos para la salud o el medio ambiente que deban declararse**.
- Si la FDS contiene una declaración distinta de esas fórmulas, el atributo 2 se califica con **No**.
- Si la FDS declara expresamente que no existen componentes que deban declararse y no presenta una lista de componentes, este ítem se marca como **No corresponde**.

- **Confiable con restricciones = 3**
- **No confiable = 1**

# Regla de presencia
- **Presente**: existe al menos un atributo exigible explícitamente consignado en la FDS.
- **No_Presente**: no existe ningún atributo exigible explícitamente consignado en la FDS.

# Códigos obligatorios
- **Confiable sin restricciones → Confiable**
- **Confiable con restricciones → Conf_CR**
- **No confiable → NO_Conf**

# Instrucciones operativas para aplicación

## Principio de aplicación
La evaluación es **documental y literal**. El evaluador no debe decidir si la FDS es técnicamente correcta; solo debe decidir si la información requerida está escrita y cómo está escrita.

## Reglas operativas para aplicación
- Evaluar exclusivamente la **Sección 3** de la FDS.
- No usar información de otras secciones para completar, corregir o inferir datos.
- Este instrumento se aplica a **FDS de pinturas que corresponden a mezclas**.
- La propia FDS debe declarar expresamente que el producto es una **mezcla**.
- Si la FDS no presenta un encabezado escrito como **Sección 3** y además no presenta uno de los encabezados aceptados en el ítem **3.0**, no se deben evaluar los ítems **3.1 a 3.2.4** con información tomada de otra sección.
- Para cada atributo marcado como observado, registrar un **fragmento textual literal** que sustente la decisión.
- Si no existe evidencia textual literal suficiente, el atributo no debe marcarse como observado.
- En caso de duda entre **5** y **3**, asignar **3**.
- En caso de duda entre **3** y **1**, asignar **1** si no existe evidencia textual suficiente.
- **No corresponde** solo puede usarse cuando la condición que lo activa esté escrita en la propia Sección 3.
- La ausencia declarada y la información no encontrada no son equivalentes y deben distinguirse en la salida.
- Una declaración expresa de reserva, confidencialidad o secreto comercial no debe tratarse igual que la omisión silenciosa.
