# Regla de calificación

## Criterio general
La asignación de **5, 3 o 1** se realiza únicamente con base en **atributos observables en la propia Sección 3 de la FDS**.

## Regla operativa
- **5**: se observan todos los atributos exigibles del ítem.
- **3**: se observa al menos un atributo exigible del ítem, pero no todos.
- **1**: no se observa ningún atributo exigible del ítem.

## Regla de aplicación
- Solo se evalúa la información consignada en la **Sección 3** de la FDS.
- No se permite completar, corregir ni contrastar información con fuentes externas.
- No se infiere información a partir del producto físico, otras secciones de la FDS o conocimiento técnico del evaluador.
- Este instrumento se aplica a **FDS de pinturas que corresponden a mezclas**.
- La propia FDS debe declarar expresamente que el producto es una **mezcla**.
- Cuando un atributo depende de una condición previa, solo se exige si esa condición está escrita en la FDS.
- Si la propia Sección 3 declara de manera expresa que no existen componentes que deban declararse, esa declaración se trata de forma distinta a la ausencia de información.
- Una declaración expresa de reserva, confidencialidad o secreto comercial no se trata igual que la omisión silenciosa, pero tampoco sustituye por sí sola la información mínima exigible del ítem.

## Regla de precedencia
En caso de duda o aparente tensión entre disposiciones del instrumento, se aplicará el siguiente orden:
1. **Regla de aplicación general**
2. **Tabla del ítem**
3. **Nota de aplicación del ítem**
4. **Ejemplos**

## Regla sobre “No corresponde”
- **No corresponde** se utiliza únicamente cuando la exigibilidad del atributo depende de una condición previa escrita en la propia Sección 3.
- **No corresponde** no debe usarse cuando la información no se encuentra, cuando la redacción es ambigua o cuando el evaluador no puede confirmar el dato.
- En **3.2.4**, el ítem se marca como **No corresponde** cuando la propia FDS declara expresamente que no existen componentes que deban declararse y, por tanto, no presenta una lista de componentes sobre la cual pueda formularse una declaración de cierre adicional.

# Notas de aplicación por ítem

## 3.0
- Solo se evalúa el encabezado de la sección.
- No se infiere el título a partir del contenido interno.
- Se aceptan formulaciones equivalentes que identifiquen de manera inequívoca la función de la sección.

## 3.1
- Este ítem verifica que la propia FDS declare expresamente que el producto es una **mezcla**.
- Que el producto pertenezca al universo de estudio no sustituye esa declaración.
- No se infiere que el producto es mezcla a partir del conocimiento externo del evaluador.

## 3.2.1
- La identidad química se evalúa solo sobre los componentes efectivamente listados o sobre una declaración expresa de que no existen componentes que deban declararse.
- Una declaración expresa de ausencia de componentes que deban declararse se califica mejor que la omisión de información.
- Expresiones genéricas como **“contiene ingredientes”**, **“mezcla de componentes”** o similares, sin individualización, se califican con **3**.
- Si la FDS usa expresiones como **“propietario”**, **“confidencial”** o **“secreto comercial”** sin individualizar suficientemente el componente, se califica con **3**.

## 3.2.2
- Se acepta número CAS u otro identificador único, siempre que pueda asociarse claramente con el componente correspondiente.
- La omisión del identificador no se trata igual que una declaración expresa de ausencia, reserva, confidencialidad o secreto comercial.
- Si la FDS lista varios componentes pero no permite asociar cada identificador con su componente, se califica con **3**.
- Si la FDS declara expresamente reserva, confidencialidad o secreto comercial, esa declaración se califica mejor que la omisión silenciosa, pero no equivale por sí sola a un identificador suficiente.

## 3.2.3
- Se acepta concentración exacta o rango de concentración.
- La concentración o el rango deben poder asociarse claramente con el componente correspondiente.
- Cuando se listan varios componentes, el orden descendente solo se evalúa si puede verificarse directamente en la propia FDS.
- Expresiones como **“trazas”**, **“mínimo”**, **“máximo”** o similares, sin cuantificación suficiente, se califican con **3**, salvo que formen parte de una expresión cuantificable clara.
- Si la FDS declara expresamente reserva, confidencialidad o secreto comercial, esa declaración se califica mejor que la omisión silenciosa, pero no equivale por sí sola a una concentración o rango suficiente.

## 3.2.4
- Este ítem evalúa si la FDS cierra expresamente la lista de componentes reportados.
- La declaración debe indicar de forma clara que no existen componentes adicionales que deban declararse en esta sección.
- Una declaración de cierre se califica con **3** cuando es genérica, parcial o no permite establecer con claridad que se refiere a componentes adicionales sujetos a declaración.
- Este ítem no demuestra exhaustividad regulatoria real de la composición; solo evalúa la presencia documental de una declaración explícita de cierre.
- Si la FDS declara expresamente que no existen componentes que deban declararse y no presenta una lista de componentes, este ítem se marca como **No corresponde**.

# Instrucciones operativas para aplicación

## Principio de aplicación
La evaluación es **documental y literal**. El modelo no debe decidir si la FDS es técnicamente correcta; solo debe decidir si la información requerida está escrita y cómo está escrita.

## Reglas operativas para GPT
- Evaluar exclusivamente la **Sección 3** de la FDS.
- No usar información de otras secciones para completar, corregir o inferir datos.
- Este instrumento se aplica a **FDS de pinturas que corresponden a mezclas**.
- La propia FDS debe declarar expresamente que el producto es una **mezcla**.
- Para cada atributo marcado como observado, registrar un **fragmento textual literal** que sustente la decisión.
- Si no existe evidencia textual literal suficiente, el atributo no debe marcarse como observado.
- En caso de duda entre **5** y **3**, asignar **3**.
- En caso de duda entre **3** y **1**, asignar **1** si no existe evidencia textual suficiente.
- **No corresponde** solo puede usarse cuando la condición que lo activa esté escrita en la propia Sección 3.
- La ausencia declarada y la información no encontrada no son equivalentes y deben distinguirse en la salida.
- Una declaración expresa de reserva, confidencialidad o secreto comercial no debe tratarse igual que la omisión silenciosa.
